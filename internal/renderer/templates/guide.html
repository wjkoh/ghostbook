Option A: Claude Desktop & Claude Web App (claude.ai)

Claude supports native remote MCP connectors with zero local installation. Your <email>:<secret-key> in the URL path authenticates you as Co-Author.

  1. Open Claude Desktop or claude.ai and go to Settings → Integrations (or Connectors) → Add Custom Connector.
  2. Set Name to {{.Book.DisplayTitle}}.
  3. Paste your personal Remote MCP Server URL below and leave Authentication set to None:
{{.BaseURL}}/u/you@example.com:<secret-key>/mcp

Using Claude Code CLI in Terminal? Run this single command:

claude mcp add --transport http {{.Book.DisplayMCPName}} {{.BaseURL}}/u/you@example.com:<secret-key>/mcp

Option B: ChatGPT Desktop & ChatGPT Web App (chatgpt.com)

ChatGPT supports remote MCP connectors directly inside the standard conversation window.

  1. Open ChatGPT and navigate to Settings → Connectors → Add Custom Connector (MCP) (enable Developer Mode if prompted).
  2. Set Name to {{.Book.DisplayTitle}} and Authentication to None.
  3. Paste your personal MCP Server URL:
{{.BaseURL}}/u/you@example.com:<secret-key>/mcp

Option C: Gemini Web App & MCP JSON Clients (Cursor, Windsurf, CLI)

Gemini Web App: Navigate to Settings → Connected Apps → Add custom app link and paste your personal MCP Server URL:

Using a local MCP JSON config? Add this block to your client's mcp_config.json:

Inline Editorial Comments & TODO Callouts (Pure-Git Workflow)

To keep 100% of editorial state inside Git, write review questions and open action items directly in chapter Markdown using blockquote callouts via patch_chapter:

[TODO · Alice Chen · 2026-11-18]: Add concrete latency numbers and benchmarks for Section 2 before final sign-off.

[Comment · Bob Rivera · 2026-11-18]: Should we split the migration checklist into a standalone appendix?

When a [TODO] or [Comment] is resolved, ask your AI agent to update the prose and remove the blockquote in the same patch_chapter commit so full discussion history stays preserved in Git.

Reporting Platform Bugs & Requesting Features

Whenever your AI agent hits tool friction or you want a new capability for the book server or MCP tools, tell your agent inside chat:

  • Bug Report: “Report a platform bug: [what happened]”
  • Feature Request: “Request a platform feature: [what would make editing easier]”

Your agent invokes report_platform_feedback, persists the ticket in SQLite along with recent tool context, and optionally emails the maintainer if Resend alerts are configured.

Complete Reference: All 13 MCP Tools

MCP Tool Name What It Does
get_table_of_contents Returns SUMMARY.md, chapter word counts, last author, and live + permalink URLs.
read_chapter Reads the full Markdown text (including any inline [TODO] or [Comment] callouts), revision SHA/number (r1..rN), and lifecycle lineage status of any chapter, SUMMARY, or STYLE_GUIDE.
search_book Searches all chapters (or a single slug) via SQLite FTS5 BM25 ranking plus exact line-level substring matching, returning highlighted snippets and 1-based line_matches.
patch_chapter Applies a surgical search-and-replace edit (or multi-hunk patches array), auto-syncs H1 titles to SUMMARY.md, commits to Git under your name/email, and pushes to the remote repo.
create_chapter Creates a new chapter or appendix file, appends it to SUMMARY.md, commits to Git, and indexes it in FTS5.
rename_chapter Moves or renames a chapter slug and/or H1 title, updating SUMMARY.md and cross-chapter links in one Git commit.
delete_chapter Removes a chapter from SUMMARY.md while preserving its historical revision permalinks and optional replacement link.
list_recent_changes Lists chronological Git commits (with r1..rN revision numbers) across the book or filtered to a single chapter.
get_commit_diff Returns the exact unified Markdown diff (+ / - lines) for any Git commit SHA or revision range.
get_chapter_blame Computes section-by-section Git blame showing which co-author last edited each heading block.
revert_chapter_revision Restores a chapter (including deleted chapters) to a prior commit SHA or revision number via a forward Git commit.
list_agent_activity Lists recent MCP and ConnectRPC tool calls from the audit log.
report_platform_feedback Submits a bug report, UX friction note, or feature request with recent tool context.
